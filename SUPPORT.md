# FireViewer Support

FireViewer is currently a small project, so there is no dedicated support team.

If you find a reproducible bug, opening an issue in the repository that owns
the affected component is useful.

Please include enough information to reproduce the problem when possible:

- repository and version or commit;
- environment;
- what you expected;
- what happened;
- non-sensitive logs or examples.

A report does not need to contain the solution.

## Technical and research questions

Questions about the architecture, OpenUSD, geospatial processing, datasets,
models, reproducibility or research are welcome.

If the discussion can be public, a GitHub issue is usually more useful because
other contributors can find it later.

For something requiring private context:

**unicornwhodev@gmail.com**

## Security

Do not disclose vulnerabilities or sensitive details through a normal issue.

Follow the project `SECURITY.md`.

## Rights, provenance and removal

For attribution problems, licensing questions, provenance corrections,
data-removal requests or concerns involving private evidence, contact:

**unicornwhodev@gmail.com**

Only send the information needed to identify the affected material.

## Emergencies

FireViewer is not monitored as an emergency service.

Do not rely on GitHub issues, email or FireViewer pages for evacuation or
emergency-response instructions.

For an active emergency, follow the relevant authorities and emergency
services.

## Response times

I read useful reports, but FireViewer is currently maintained mostly by one
person and response times can vary.

Please do not interpret a slow response as confirmation that a report is
incorrect or unimportant.
